# 📢 Notification System Dashboard

A simple full-stack notification system built for campus hiring evaluation.  
This project demonstrates REST API design, logging middleware integration, and a responsive frontend UI.

---

## 🚀 Features

- 🔔 Fetch and display notifications
- 🎯 Priority-based sorting (Placement > Result > Event)
- ⏱️ Latest notifications shown first
- ✔ Mark notifications as done
- 🔄 Refresh notifications
- 🗑 Clear all notifications
- 🧠 Smart API fallback (external + local)
- 📜 Logging middleware for all API calls

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** VS Code, Git, GitHub
